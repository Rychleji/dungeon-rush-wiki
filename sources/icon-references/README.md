# Unused pet icon reconstruction drafts

Superseded by the user-provided original circular portraits in `../pet-icons-complete.png`. These generated drafts are not loaded by the calculators and do not need to be uploaded.

Created with the built-in image-editing tool from the user screenshots and `../icons.webp`. The original source sheet is preserved.

These are reconstructed assets, rather than untouched game exports. They remove the level labels and complete the clipped left edges for calculator use.
